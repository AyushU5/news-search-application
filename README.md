# 📰 AI News App

A modern Flask web application that fetches real-time news articles using NewsAPI.

## ✨ Features

- 🔍 Search news by topic
- 📰 Live news updates
- 🖼️ News images
- 📱 Responsive UI
- 🌙 Modern dark theme
- ⚡ Fast Flask backend
- 🔒 API key secured using `.env`

---

## 🛠️ Tech Stack

- Python
- Flask
- HTML5
- CSS3
- Requests
- NewsAPI
